I ran the numbers on my own monitoring setup last month. An always-on agent watching a production system costs about a dollar an hour while idle. That's $720 a month before it does anything interesting.

Add tool calls, reasoning chains, and the retry loops real automation needs, and variable burn passes $800. A SaaS seat for a person using traditional tools is $200.

The enterprise math still works. Replace a senior engineer's repetitive workflows and token cost is noise. Mid-market doesn't clear the bar. Small teams don't either. The premium hasn't crossed the threshold for the businesses that would benefit most.

That cuts across both paths. Teach machines to drive interfaces built for people, or build new ones aimed at machines. Native costs engineering time. Mimicry costs tokens. The fork doubles the investment without doubling the return.

Then security. A supply-chain attack on one skills marketplace shipped 341 malicious skills and over 9,000 compromised installs. Standard protocols were supposed to make agents safer. They also make one vulnerability scale across everything that speaks the protocol.

Four companies are shipping four competing protocols. The industry keeps calling this USB-C for AI. It looks more like four charging ports, each backed by a different incentive.

Then the brownfield number. Roughly 40,000 grocery stores in the United States. Converting them to purpose-built dark stores runs into tens of billions. That's one industry, in one country.

So mimicry isn't an interim hack. For much of the world it's the only interface layer there will ever be. It also breaks whenever someone ships a CSS change.

Both are stuck. Native can't scale to the world that exists. Mimicry can't stabilize in it.

I don't have a resolution and I'm not sure one exists yet. The harder question isn't which path wins. It's whether the split is what keeps both fragile.

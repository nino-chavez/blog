A mining pass over my full session corpus found 122 `pkill` invocations across 16 projects. Most were hunting stray preview servers that some earlier turn had started and lost track of.

Nobody decided to spend context on process janitoring. It is what an agent does by default when the environment offers it no cheaper move.

That is the whole thesis. A correction typed into chat lives exactly one session. A rule written into project instructions survives, but it is still prose an agent reads and then chooses to apply, and adherence drifts under pressure. So the durable fix is not repetition. It is changing what the environment makes easy, possible, and impossible.

Three levels, and the discipline is stopping at the lowest one that holds.

Helpers make the correct path the cheapest path. Small wrappers on PATH: one manages a preview server with a pidfile, one collapses any build or test run to a single line of signal, one replaces hand-written polling loops. Compliance happens because it is the path of least resistance, not because anyone was persuaded.

Hooks deny the bad path at the tool boundary, before it runs. A sixty-day log audit found half of all file Reads were re-reading something already in context — worst case, one file read 184 times in a single session — and full-resolution screenshots costing around 4,800 image tokens where a 1000px copy carries the same information for about 900. Waste at the Read boundary then compounds, because every wasted token gets re-read on each later turn through the prompt cache, an observed 41× multiplier.

So a hook denies an oversized image once, having already written the downscaled copy, and names the path to read instead. It fired on the agent mid-way through building this demo series, reviewing a screenshot of demo 01. The guard was right and the smaller copy was used.

Then there are 553 exchanges mined with the same shape: the agent ends its turn on a permission-seeking question, and the answer is one word. That was never a decision point. It was a reflex, and it now has three layers aimed at it, because each layer alone leaked.

CI ratchets are level three, where a convention becomes something no session can ship past.

A rule is only as durable as the mechanism carrying it.

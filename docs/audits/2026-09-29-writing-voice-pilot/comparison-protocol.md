# Judge the writing before revealing the instructions

Frozen before generating either candidate, 2026-09-29.

Both writers receive essay-brief.md, the same canonical guide and reader contract, the same prose-clarity reference, and the same example K. One receives the small addendum recorded in its brief. No private messages enter either prompt. This tests an editorial package on one new topic, not individual rules or an unaided-writing model.

Separate read-only workers return one draft each. The parent checks fidelity without rewriting either candidate or showing one to its competitor. If a factual defect makes a candidate unusable, report it; do not silently improve an arm. Randomize neutral labels after receipt. Keep the key apart from the comparison. Publish actual routing receipts and distinguish selected from runtime-reported models. Different or unverified runtimes limit causal interpretation.

Nino reads the anonymous pair before seeing the key or a model's preference. Ask which he would keep, allowing neither or a tie; which sentences sound unlike him; and which needs less rewriting. Rate resemblance, naturalness, factual fidelity, and usefulness separately if those judgments differ. Do not equate length or sentence metrics with preference. No model vote supplies Nino's judgment.

One pair is the entire pilot. Do not rerun to obtain a winner. Existing user feedback helped construct the addendum, so the photography exercise is not held-out evidence. The new topic is a transfer probe with no known human target. A future generalization test must reserve whole independently authored pieces and threads before profile construction and compare against the existing baseline, preferably also a wrong-writer control. Do not proceed to that larger experiment automatically.
